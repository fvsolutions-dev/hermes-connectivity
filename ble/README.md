# Hermes BLE Nodes
[![PyPI version](https://badge.fury.io/py/qt-ble-discovery-widget.svg)](https://pypi.org/project/hermes-ble-nodes)

A collection of hermes nodes to interface with BLE.

## Installation

### From PyPI

Install the package directly from PyPI using pip:

```bash
pip install hermes-ble-nodes
```

### From Source

Clone the repository and install dependencies:

```bash
git clone https://github.com/fvsolutions-common/hermes-ble-nodes
pip install -e hermes-ble-nodes
```

## Development

This project depends on UV for managing dependencies.
Make sure you have UV installed and set up in your environment.

You can find more information about UV [here](https://docs.astral.sh/uv/getting-started/installation/).

```bash
uv venv
```

```bash
uv sync --all-extras --dev
```
